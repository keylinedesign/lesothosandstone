# Updating the Lesotho Stone website

The site is plain static HTML/CSS/JS generated by a small dependency-free Node script.
The finished site is the `public/` folder. Upload it to any web host as-is.

```
content/site.json          ← ALL copy, contacts, products, specs, project photos
build.mjs                  ← page templates + generator (one section per page type)
src/assets/css/tokens/     ← design tokens (colours, type, spacing, base) — from the design system
src/assets/css/components.css ← every site component (header, hero, cards, grids, forms, footer…)
src/assets/js/site.js      ← progressive enhancement (menu, reveals, parallax, filters, lightbox, forms)
src/assets/img/            ← local images (logo)
design-system/             ← the Lesotho Stone design system (readme.md = brand rules, guidelines/, ui_kits/)
public/                    ← GENERATED. Never edit by hand; it is wiped on every build.
```

## Workflow (every change)

1. Edit `content/site.json` for content, `src/assets/css/*` for styling, `build.mjs` for page structure.
2. Rebuild: `node build.mjs` (Node 18+; no `npm install` needed).
3. Preview: `python3 -m http.server 8123 -d public` then open http://localhost:8123/.
   Check desktop (1440px) and mobile (390px) widths: no horizontal scroll, menu opens, project filters + lightbox work.
4. Commit both the source change **and** the regenerated `public/`.

## Common tasks

**Edit copy or contact details** — find the string in `content/site.json` (`home`, `about[]`, `distribution`, `footerAbout`, `contactList[]`, `site.headerPhone`, `site.formEmail`) and change it. Keep the owner's wording verbatim unless asked to change it (the source includes deliberate-to-keep typos such as "distrubition", "availibity", "Lakaokaneng").

**Add a product** — append the name to `categories.<custom|cladding|bricks>.products`. The page `products/<category-slug>/<product-slug>/` is created automatically, plus its tile, menu entries and "next product" link. If specs are known, add them under `specs["Exact Product Name"]` with `format`, `size`, `unitsPerM2`, `m2PerPallet` (e.g. `"300 x 160mm"` — lowercase x, no space before mm). Renaming a product changes its URL.

**Add project photos** — add `{ "cat": "<one of projectFilters>", "image": "<url or assets/img/...>", "title": "<same as cat>", "n": <number> }` to `projects[]`. A new category also needs adding to `projectFilters`. The home page shows the projects at the indexes listed in `homeProjectPreview`.

**Use local images instead of the live-site URLs** — images are currently hotlinked from `https://lesothosandstone.co.za/wp-content/uploads/...` (so they only load where that server is reachable). To self-host: download them into `src/assets/img/` (keep the file names, e.g. `src/assets/img/2020/12/Strip-Walling.1.jpg`), then in `content/site.json` replace `https://lesothosandstone.co.za/wp-content/uploads/` with `assets/img/` (also the `U` key). Relative paths are resolved per page automatically. New photos can be added the same way.

**Add a page** — add a `page(route, navKey, title, description, (b) => html)` call in `build.mjs`, add its route to `R`, and (if it belongs in the menu) to the `items` list in `header()`. Build markup from the existing partials (`hero`, `reveal`, `eyebrow`, `button`, `frame`, `parallax`, `contactList`, `field`) and existing CSS classes before writing new CSS.

**Change colours / fonts / spacing** — edit tokens in `src/assets/css/tokens/`, not hard-coded values in components. Fonts are Archivo (variable width) + IBM Plex Mono, loaded from Google Fonts in `layout()`.

**Forms** — the site is static, so "Become a Distributor" and "Leave a message" open the visitor's email app with the filled-in fields, addressed to `site.formEmail`. To use a form service instead (Formspree, Netlify Forms, a PHP mailer…), set the `<form action>` in `distributorForm()` / the contact page and remove the `data-mailto` attribute.

## Brand rules (from design-system/readme.md — read it for the full set)

- Dark & dramatic: basalt `#1B1B1D` ground, at most two background colours per page; earth `#47362A` is the only alternate band colour.
- Dune `#C9BCA4` is the single accent (primary buttons, active states, 1–2 highlighted words). No blues, no gradients other than photo scrims.
- Display type: Archivo 900, width 62, uppercase, line-height .88. Labels: IBM Plex Mono 11–12px uppercase, +.16em. Body: Archivo 16/1.6.
- Sharp corners everywhere; no shadows on cards; 1px hairlines; the 6px chalk bar opens major blocks.
- Typographic glyphs only (→ ← ✕ ● +). No emoji, no icon fonts. Never redraw the logo (only a raster JPEG exists; it is inverted on dark).
- Motion: expo-out `cubic-bezier(.16,1,.3,1)`; reveals fade + lift 40px; everything respects `prefers-reduced-motion`.
- CTAs are short: Learn More, Become a Distributor, See more, Send, Contact Us.
