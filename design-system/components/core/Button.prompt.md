Square, uppercase mono-label button with a sliding arrow — use for every CTA (Learn More, Become a Distributor, Send).
```jsx
<Button variant="primary" href="/about-us/">Learn More</Button>
<Button variant="outline">Become a Distributor</Button>
<Button variant="link">See more</Button>
```
Variants: primary (dune fill), outline (on dark), dark (on light/accent grounds), link (underlined text). Sizes sm/md/lg. icon="none" hides the arrow.
